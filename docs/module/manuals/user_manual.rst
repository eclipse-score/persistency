Persistency User Manual

Overview
========

This manual describes the integration and usage of the Persistency module (Key-Value-Storage, KVS) for
application developers. It refers to the sources of the information instead of repeating them: feature
:need:`feat__persistency` with its architecture :need:`doc__persistency_kvs_architecture` and component
:need:`comp__persistency_kvs` with its requirements :need:`doc__kvs_requirements`.

Environment Needs
=================

Supported languages and operating systems: :need:`feat_req__persistency__cpp_rust`,
:need:`feat_req__persistency__os_agnostic`. Toolchains, Bazel version and target platforms are defined in
`MODULE.bazel <https://github.com/eclipse-score/persistency/blob/main/MODULE.bazel>`__,
`.bazelversion <https://github.com/eclipse-score/persistency/blob/main/.bazelversion>`__ and
`.bazelrc <https://github.com/eclipse-score/persistency/blob/main/.bazelrc>`__.

Dependencies
------------

Dependencies, versions and licenses are listed in the SBOM generated by the Bazel target ``//:sbom_product``.

Module Configuration Details
============================

A KVS instance is configured via ``KvsBuilder`` (C++ and Rust), see `API Reference`_. The behavior of the
component, including its configuration, is specified in :need:`doc__kvs_requirements`.

Configuration Effects
---------------------

Loading, flushing and snapshot handling are shown in the dynamic architecture of
:need:`doc__persistency_kvs_architecture`.

Examples
========

See `examples/README.md <https://github.com/eclipse-score/persistency/blob/main/examples/README.md>`__.

API Reference
=============

Logical interface: :need:`logic_arc_int__persistency__interface`. The API is documented in the source code
(C++: `score/kvs <https://github.com/eclipse-score/persistency/tree/main/score/kvs>`__, Rust: crate ``rust_kvs``,
``cargo doc -p rust_kvs``).

Performance Considerations
==========================

Performance properties are defined by :need:`feat_req__persistency__fast_access`,
:need:`feat_req__persistency__cached_access` and :need:`feat_req__persistency__write_amplification`;
verification results are documented in :need:`doc__persistency_verification_report`.

======================

The Bazel integration is described in
`examples/README.md <https://github.com/eclipse-score/persistency/blob/main/examples/README.md>`__.
The application shall fulfill the assumptions of use listed in :need:`doc__persistency_safety_manual` and
:need:`doc__persistency_security_manual`.
